# v0.2.0 实现总结

## 数值

| 指标 | v0.1.0 | v0.2.0 |
|------|--------|--------|
| 适配器数 | 3 | 6 |
| TUI 快捷键 | 8 | 12 |
| trait 方法 | 7 | 15 |
| 测试数 | 14 | 21 |
| 源文件 | 15 | 18 |
| 配置文件 | 1 (config.toml) | 2 (settings.toml + mirrors.toml) |

## 新增适配器

- **pip** — Python 生态，`pip config` 命令模式，自动检测 pip3/pip/python3 -m pip
- **Go** — GOPROXY 环境变量，shell profile 模式
- **Pacman** — Arch Linux mirrorlist，sudo 文件模式，插入最前 + 保留回退

## 架构改进

- **Config 统一访问**：`mirrors_for()` 消除 `app.rs` 6 处硬编码 match，新增适配器不再需改 `app.rs`
- **备份还原**：trait 层统一，切换前自动备份，`r`/`R` 一键还原/重置
- **sudo 统一入口**：`run_sudo()` 自动选择静默或交互模式，5 次迭代修复 ratatui 渲染问题
- **配置文件拆分**：`settings.toml`（设置+主题）+ `mirrors.toml`（镜像数据），自动迁移旧 `config.toml`

## TUI 增强

- 布局从右三分改为上下分：上部管理器+镜像源，底部全局快捷键栏
- 新弹窗：刷新建议、批量测速结果、还原/重置确认
- 冲突警告：reflector.service 检测

## 主题系统

- `settings.toml` 中 `[themes.dark]` / `[themes.light]` 预设
- 支持颜色名 + `#RRGGBB` 十六进制
- 未设置字段回退到内置默认
- `Palette::from_theme()` 构建运行时配色

## 经验教训

1. **ratatui diff 渲染**与手动终端操作不兼容。`Clear(All)` 后必须配合 `terminal.clear()` 重置缓冲区
2. **适配器语义匹配**：不同包管理器的配置方式不同（单值 vs 列表），应匹配而非统一
3. **sudo 密码输入**：不操作 alternate screen，只切换 raw mode，是保持 ratatui 状态的最安全方式
4. **旧配置兼容**：`serde(default)` + `fill_defaults()` 保证升级平滑
