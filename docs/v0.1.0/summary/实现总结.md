## 技术决策

1. **同步阻塞测速**：v0.1.0 使用 `reqwest::blocking`，避免 tokio 集成复杂度
2. **配置与适配器分离**：Config 负责持久化，Adapter 负责运行时操作
3. **Shell profile 修改**：Homebrew 通过环境变量切换，写入 `.zshrc`/`.bashrc`
4. **Cargo config 合并**：智能合并已有 `~/.cargo/config.toml`，不破坏非 source 段
