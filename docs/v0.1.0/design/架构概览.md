# MirroMan v0.1.0 架构概览

## 技术栈

| 层 | 技术 | 用途 |
|----|------|------|
| TUI 框架 | ratatui 0.29 + crossterm 0.28 | 终端 UI 渲染与键盘事件处理 |
| 配置 | toml 0.8 + serde + directories 6 | 配置的序列化/反序列化与跨平台路径 |
| HTTP | reqwest 0.12 (rustls-tls, blocking) | 镜像源测速 |
| 错误处理 | anyhow 1 + thiserror 2 | 错误传播与类型化错误 |
| 日志 | tracing 0.1 + tracing-subscriber 0.3 | 结构化日志 |
| 异步 | tokio 1 (预留) | 异步运行时（v0.1.0 使用同步阻塞模式） |

## 架构图

```
main.rs
  ├─ config::Config::load()      → TOML 文件读取
  ├─ adapters (3 个)             → PackageManagerAdapter trait
  │   ├─ CargoAdapter            → ~/.cargo/config.toml
  │   ├─ NpmAdapter              → npm config set registry
  │   └─ HomebrewAdapter         → shell profile 环境变量
  ├─ app::App::new(config, adapters)
  ├─ tui::init()                 → ratatui + alternate screen
  └─ event loop:
      ├─ terminal.draw(ui::draw) → 渲染界面
      └─ app.handle_event()      → 按键分发
```

## 模块职责

| 模块 | 职责 |
|------|------|
| `main.rs` | 入口点，编排初始化流程 |
| `app.rs` | App 状态管理、事件循环、按键分派 |
| `config.rs` | 配置结构体定义、TOML 读写、默认配置生成 |
| `mirror.rs` | Mirror 结构体（名称/URL/启用/延迟） |
| `tui.rs` | 终端初始化/恢复（raw mode、alternate screen） |
| `ui.rs` | 界面渲染（面板、表格、弹窗） |
| `adapters/mod.rs` | PackageManagerAdapter trait 定义 |
| `adapters/cargo.rs` | Cargo 适配器实现 |
| `adapters/npm.rs` | npm 适配器实现 |
| `adapters/homebrew.rs` | Homebrew 适配器实现 |
| `utils/command.rs` | 系统命令执行封装 |
| `utils/os.rs` | OS 检测、可执行文件查找 |
| `utils/paths.rs` | 路径工具（~ 展开等） |

## 数据流

```
用户按键 → crossterm event → app.handle_event()
  ├─ Enter     → adapter.switch_mirror() → 系统命令/文件写入
  ├─ t         → adapter.test_mirror()   → reqwest HTTP HEAD
  ├─ a         → 弹出添加弹窗 → 写入 config → config.save()
  ├─ d         → 确认删除弹窗 → 移除镜像 → config.save()
  └─ ↑↓ Tab    → 更新选中索引

每次循环 → terminal.draw(ui::draw) → ratatui 渲染
```
