# MirroMan 使用指南

## 启动

在终端中运行：

```bash
mirroman
```

首次运行会自动生成默认配置文件，包含常用国内镜像源。

## 界面说明

- **左面板（包管理器）**：列出支持的包管理器。`✓` 表示该工具在当前系统上可用。
- **右面板（镜像源）**：当前选中包管理器的镜像源列表，含名称、URL、状态、延迟。
- **底部栏**：快捷键提示和操作反馈。

## 基本操作

### 切换镜像源

1. `Tab` 切换到右面板
2. `↑↓` 选中目标镜像
3. `Enter` 切换

Cargo 切换会修改 `~/.cargo/config.toml`，npm 切换执行 `npm config set registry`，Homebrew 切换写入 shell profile。

### 测试镜像速度

1. 选中目标镜像
2. 按 `t`
3. 测速结果（延迟 ms）显示在底部

### 添加镜像

1. 按 `a`
2. 输入名称，`Enter` 切换到 URL 输入
3. 输入 URL，`Enter` 确认

### 删除镜像

1. 选中目标镜像
2. 按 `d`
3. `y` 确认 / `n` 取消

## 配置文件

### 位置

- **Linux**: `~/.config/mirroman/config.toml`
- **macOS**: `~/Library/Application Support/com.mirroman.MirroMan/config.toml`

### 格式

```toml
[settings]
default_manager = "Cargo"
test_timeout_secs = 5

[cargo]
[[cargo.mirrors]]
name = "清华 TUNA"
url = "https://mirrors.tuna.tsinghua.edu.cn/git/crates.io-index.git"

[npm]
[[npm.mirrors]]
name = "淘宝 npmmirror"
url = "https://registry.npmmirror.com"

[homebrew]
[[homebrew.mirrors]]
name = "中科大 USTC"
url = "https://mirrors.ustc.edu.cn/brew.git"
```

手动编辑配置文件后，重新启动 MirroMan 即可看到变更。
