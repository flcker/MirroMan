# v0.1.0 变更说明

## 概述

MirroMan 首个可用版本，实现基础 TUI 镜像源管理功能。

## 新建文件

```
Cargo.toml                  # 项目依赖声明
src/main.rs                  # TUI 入口点
src/app.rs                   # App 状态 + 事件循环
src/config.rs                # 配置读写
src/mirror.rs                # Mirror 结构体
src/tui.rs                   # 终端初始化
src/ui.rs                    # 界面渲染
src/adapters/mod.rs          # Adapter trait
src/adapters/cargo.rs        # Cargo 适配器
src/adapters/npm.rs          # npm 适配器
src/adapters/homebrew.rs     # Homebrew 适配器
src/utils/command.rs         # 命令执行
src/utils/os.rs              # OS 检测
src/utils/paths.rs           # 路径工具
README.md                    # 项目说明
CHANGELOG.md                 # 版本记录
plans/v0.1.0/feat_mirroman_0_1_0_init_2026_05_16.md
docs/v0.1.0/design/架构概览.md
docs/v0.1.0/guides/使用指南.md
```

## 依赖

| Crate | 版本 | 用途 |
|-------|------|------|
| ratatui | 0.29 | TUI 框架 |
| crossterm | 0.28 | 终端控制 |
| toml | 0.8 | 配置解析 |
| serde | 1 | 序列化 |
| directories | 6 | 跨平台路径 |
| anyhow | 1 | 错误处理 |
| thiserror | 2 | 错误类型 |
| reqwest | 0.12 | HTTP（测速） |
| tokio | 1 | 异步运行时（预留） |
| tracing | 0.1 | 日志 |
| tracing-subscriber | 0.3 | 日志订阅 |

## 限制

- 测速为同步阻塞模式（后续版本将改为异步）
- Homebrew 镜像切换后需 `source ~/.zshrc` 或重开终端生效
- 不支持 Windows 平台完整测试
- 不支持插件化自定义包管理器
